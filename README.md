# ArrestIQ

ArrestIQ is a private iPhone application built with SwiftUI and developed by **Code 3 Coders**.

The application is designed to streamline California law enforcement custody and release decisions by providing a fast, structured workflow for criminal offense identification, bail calculations, pre-arraignment release assessments, and statutory reference information.

This repository is maintained as a private development project and is not intended for public distribution.

---

## Purpose

ArrestIQ was created to improve efficiency, consistency, and accuracy when evaluating criminal charges, bail requirements, and pre-arraignment release eligibility.

The application focuses on:

- Rapid criminal offense identification
- Accurate bail schedule reference and calculation
- Structured custody and release assessments
- Consistent application of release protocols
- Practical patrol usability
- Reduced reliance on manual cross-referencing of legal documents

---

## Core Features

### Criminal Offense Database

- Searchable California criminal offense database
- Penal Code, Vehicle Code, Health and Safety Code, and other applicable statutes
- Search by statutory section or offense description
- Felony and misdemeanor classifications
- Bail schedule amounts and release protocol designations
- Support for criminal enhancements and qualifying conditions

### Custody and Release Assessment

- Guided arrest assessment workflow
- Cite and Release (CR) evaluations
- Book and Release (BR) evaluations
- Bail Condition (BC) evaluations
- Conditional questions based on selected charges
- Identification of applicable release exceptions
- Custody disposition recommendations based on entered information

### Bail Calculation

- Automated bail calculations using applicable schedules
- Multiple criminal charge support
- Separate victim and criminal act identification
- Same-act and separate-act bail considerations
- Applicable enhancements and qualifying prior convictions
- Special handling for qualifying offenses
- Consolidated bail assessment results

### Charge and Case Management

- Multiple charge and count management
- Individual victim assignment
- Duplicate charge functionality
- Charge editing and deletion
- Incident and criminal act grouping
- Locally saved arrest assessment drafts
- Draft reset and recovery safeguards

### Legal Reference Resources

- Contra Costa County bail schedules
- Pre-Arraignment Release Protocol (PARP) guidance
- Penal Code § 853.6(i) exceptions
- Court scheduling guidance
- Own-Recognizance Release Agreement (CR-220)
- Bail increase request documentation
- Relevant statutory and procedural reference information

### User Interface

- Native SwiftUI-based design
- Streamlined navigation
- Searchable offense selection
- Interactive charge management
- Context-sensitive assessment questions
- Clear custody disposition results
- Modern, patrol-oriented interface
- Local data storage
