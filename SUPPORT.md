# ArrestIQ Support

Welcome to the official support repository for **ArrestIQ** by **Code 3 Coders**.

ArrestIQ is a mobile law enforcement reference and decision-support application designed to streamline California criminal offense identification, bail calculations, and pre-arraignment release assessments through structured workflows and integrated legal reference resources.

---

# Support Requests

For bug reports, feature requests, troubleshooting assistance, or general support, please contact the development team directly through GitHub.

## How to Request Support

### 1. Open a GitHub Issue

Please create a new Issue in this repository and include:

- Device model
- iOS version
- ArrestIQ version
- Description of the issue
- Steps to reproduce the issue
- Screenshots, if applicable

Providing detailed information helps the development team diagnose and resolve issues more efficiently.

**Important:** Do not include personally identifiable information, criminal justice information (CJI), actual arrest records, or confidential investigative details in support requests.

# Current Application Scope

Current releases of ArrestIQ focus on:

- California criminal offense identification and search
- Contra Costa County felony and misdemeanor bail schedules
- Pre-Arraignment Release Protocol (PARP) assessments
- Cite and Release (CR), Book and Release (BR), and Bail Condition (BC) classifications
- Multiple charge and count management
- Victim and criminal act grouping
- Bail calculations involving multiple offenses and applicable enhancements
- Statutory exceptions and release eligibility considerations
- Court scheduling and legal reference resources
- Locally saved arrest assessment drafts
- Offline access to core application functionality

ArrestIQ currently focuses on Contra Costa County bail schedules and release procedures. Future updates may expand jurisdictional coverage and application functionality.

# Privacy and Data Handling

ArrestIQ is designed with a local-first storage philosophy.

- No cloud storage of arrest assessment data operated by Code 3 Coders
- No external AI processing of user-entered arrest assessment information
- No third-party sale of user data
- No user account required
- Core decision-support functions operate locally on the device
- Saved arrest assessments remain stored locally unless the user intentionally shares information through supported device functionality

Users should avoid entering unnecessary personal or confidential information into arrest assessments.

Please review the official Privacy Policy for additional information.

# Important Notice

ArrestIQ is an informational law enforcement reference and decision-support tool. It does not replace:

- Officer judgment and discretion
- Agency policies and procedures
- Current California statutes
- Official county bail schedules
- Judicial orders and magistrate determinations
- Applicable pre-arraignment release requirements
- Legal review or supervisory oversight

Users remain responsible for independently verifying custody and release decisions against current official sources and ensuring compliance with applicable laws, court orders, and agency requirements.

ArrestIQ is independently developed and is not affiliated with, endorsed by, or an official application of any government or law enforcement agency.
